# نافذة (Nafitha)

**نافذة** تطبيق مجاني ومفتوح المصدر لتشغيل أجهزة افتراضية بأنظمة **macOS وWindows 11 وLinux** على أجهزة ماك بمعالجات Apple silicon. يعتمد فقط على إطار `Virtualization.framework` من Apple، دون امتدادات نواة أو QEMU أو خدمات خلفية.

[English](README.md)

## المزايا

- **macOS:** ينزّل أحدث نسخة رسمية من Apple ويثبّتها تلقائيًا، وتتغيّر دقة الشاشة مع حجم النافذة.
- **Windows 11 ARM:** يثبّت النظام من ملف ISO مع إعداد تلقائي اختياري. يستخدم قرص NVMe الذي يتعرّف عليه Windows دون تعريفات إضافية.
- **Linux ARM64:** يثبّت أي توزيعة من ملف ISO، مع مشاركة الحافظة عبر `spice-vdagent`.
- مشاركة المجلدات عبر VirtioFS.
- تعليق الجهاز (Suspend) واستئنافه من حيث توقف. (على macOS 27.0.1 يرفض إطار أبل حفظ أي جهاز EFI بخطأ «permission denied». عندها يبقى الجهاز يعمل ويظهر الخطأ.)
- نسخ الأجهزة فوريًا عبر استنساخ APFS، فلا تشغل النسخة مساحة إضافية حتى تتغيّر.
- واجهة **بالعربية والإنجليزية** مع دعم كامل للاتجاه من اليمين إلى اليسار، وتدعم VoiceOver والتنقل بلوحة المفاتيح.

## المتطلبات

- جهاز ماك بمعالج Apple silicon (M1 أو أحدث)
- macOS 14 أو أحدث
- للبناء: Xcode 26 أو أحدث

## البناء والتشغيل

```bash
make run
```

## تثبيت Windows 11

1. نزّل ملف **Windows 11 ARM64 ISO** من [موقع Microsoft](https://www.microsoft.com/software-download/windows11arm64).
2. يُنصح بتنزيل [`virtio-win.iso`](https://fedorapeople.org/groups/virt/virtio-win/direct-downloads/stable-virtio/virtio-win.iso) لتعريف الشبكة، ويثبّته التطبيق تلقائيًا عند أول تسجيل دخول.
3. اختر **جهاز افتراضي جديد ← Windows 11** وأبقِ خيار **إعداد Windows تلقائيًا** مفعّلًا.
4. عند ظهور عبارة *Press any key to boot from CD or DVD* انقر داخل النافذة واضغط أي مفتاح.
5. بعد الوصول إلى سطح المكتب أطفئ خيار **الإقلاع من وسائط التثبيت**.

لا يوفر الإطار شريحة TPM افتراضية، لذلك يتجاوز الإعداد التلقائي فحص TPM وSecure Boot. تفعيل Windows يحتاج ترخيصك الخاص.

## غير مدعوم بسبب حدود الإطار

- تسريع الرسوميات ثلاثية الأبعاد وDirectX في Windows
- الشبكة الجسرية (Bridged)، فهي تحتاج صلاحية مقيّدة من Apple
- تمرير أجهزة USB
- الأنظمة بمعمارية x86/x64
